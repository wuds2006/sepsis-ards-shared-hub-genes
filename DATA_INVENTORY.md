# Data and Materials Inventory

Machine-readable companion: [`DATA_INVENTORY.csv`](DATA_INVENTORY.csv).
Retrieval runbook: [`FETCH_PUBLIC_DATA.md`](FETCH_PUBLIC_DATA.md).

This study is a **secondary analysis of public data**. No new participants were enrolled, no
identifiable personal data were accessed, and no raw public data are redistributed in this
repository (licence and size both prohibit it). What is provided here is the complete,
versioned **input inventory** plus the code that turns those inputs into every number in the
paper.

## 4. What is and is not in this repository

**Included**

- `analysis/` — 217 scripts (R / Python / shell), plus `run_all.sh` driving 17 stages mapped to Supplementary Methods S1–S14.
- `results/` — 369 derived numeric outputs (CSV / TXT / XLSX) organised by the 13 analysis modules.
- `manuscript/` — manuscript text, supplementary methods, figure legends, and all 27 supplementary tables as submitted.
- `environment/` — interpreter versions and the package inventory extracted from the scripts.
- `DATA_INVENTORY.md` / `DATA_INVENTORY.csv`, `FETCH_PUBLIC_DATA.md`, `RESULTS_TO_CODE.md`, `METHODS_TO_CODE.md`, `PATHS.md`, `MANIFEST.txt`, `code_archive.zip`.

**Deliberately excluded** (see `.gitignore`)

- Raw public data (`00_rawdata/`) — re-download with `FETCH_PUBLIC_DATA.md`; the eQTLGen file alone is ~2.5 GB.
- Large single-cell binary objects (`*.rds`, `*.h5ad`, `*.h5seurat`) — regenerated by the scripts.
- Figure TIFFs — shipped with the manuscript, not with the code archive.

## 5. Provenance caveats

- Ancestry and sampling-time annotation is incomplete for GSE76293, GSE69528, and GSE100159 in the
  local series records; this is disclosed in Supplementary Methods S1 and in Supplementary Table S26.
- Exact per-file download dates were not captured for the GEO series matrices and GWAS summary
  statistics. Where known they are given above; otherwise the entry reads `not recorded`
  rather than an inferred date.
