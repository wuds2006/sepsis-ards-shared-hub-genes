# RESULTS_TO_CODE.md — every RESULTS number mapped to the code that produces it

This file maps each subsection of the manuscript RESULTS to the analysis stage
(one Supplementary Methods section each), the scripts that implement it, and
the archived output file(s) in `results/` from which every number is read.
Run the stages through `analysis/run_all.sh` (stage keys below match its
registry). Section S1 (data acquisition) feeds all downstream stages and is
listed only once.

Numbers quoted are the manuscript's reported values (02_Manuscript_Revised.md,
RESULTS, 3,494-word revision of 2026-10-21) — use them as the acceptance
targets when re-running. Note that `results/` stores files flat within each
numbered directory (e.g. `results/08_singlecell/`), even though the live
pipeline writes into subdirectories (`08_singlecell/knockout/` etc.); the
archive flattening happened at packaging time and both views contain the same
files.

## Provenance notes (read before re-running)

1. **Superseded in-place revisions.** Where a fix script replaced an earlier
   run on the same outputs, the archive keeps both and `run_all.sh` runs the
   final one: GSE167363 annotation (`step3e_fix3_annotate.R` final), UPP1
   docking box (`step57` final; original kept as
   `docking_site_results_OLD_UPP1box.csv`), quantitative CellChat
   (`step110`/`step111` regenerate `netP$strength/weight` inside the saved
   CellChat objects and export the CSVs behind the manuscript's MIF/MHC
   numbers — see the `*_recalc_2026-10-19.csv` files).
2. **External-binary steps.** AutoDock Vina (invoked by `step4_*`), SMR v1.03,
   PLINK and LDSC are not redistributed. SMR+HEIDI has a documented runbook
   (`step117_run_smr_heidi.sh`); its archived outputs are authoritative. The
   LDSC rg/h² numbers are preserved as the original run logs
   (`results/04_MR_SMR/ldsc_*.log`, added 2026-10-22); the ~1-GB munged inputs
   are regenerated by `prepare_ldsc.py`.
3. **API-provenance closures.** ChEMBL (`step115`), the primary Enrichr query
   (`step116`), Open Targets (`step68`) and the Enrichr negative controls
   (`step67`, `step76`) re-issue the documented queries; live databases may
   have moved on since the access dates recorded in the README.
4. **HEIDI R approximation.** `step1d_heidi.R` is a no-LD-reference
   approximation kept only as history (`HEIDI_results_DEPRECATED_Rapprox.csv`);
   the manuscript's HEIDI values come from SMR v1.03 via `step117`.
5. **Figure-only outputs.** `step2e_nomogram.R` writes nomogram/ROC/calibration/
   DCA figures (and prints the model AUCs); the archived numeric record of the
   prediction-model results is `06_external_validation/muc1_sensitivity.csv`
   and `validation_AUC_combined.csv`. The four-cohort expression boxplots
   (Result 4) are figure panels computed directly from the expression
   matrices.
6. **Absolute paths.** See `PATHS.md` for the full inventory and porting steps.
